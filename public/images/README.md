# Imagens do Portfólio

## Logo da Arquiteta

Coloque aqui o arquivo da logo:
- Nome sugerido: `logo.png` ou `logo.jpg`
- Tamanho recomendado: 100x100px a 200x200px
- Formato: PNG com fundo transparente (recomendado) ou JPG

Enquanto você não adicionar a logo real, o código usa um placeholder do Unsplash.

Para adicionar sua logo:
1. Copie o arquivo de imagem para esta pasta (`public/images/`)
2. Renomeie para `logo.png` (ou atualize o caminho em `components/Navbar.tsx`)
3. A logo aparecerá automaticamente no site
