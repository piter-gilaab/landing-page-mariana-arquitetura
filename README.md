# 🏛️ Portfolio Arquitetura

Landing page desenvolvida com foco em apresentação de projetos arquitetônicos, da arquiteta Mariana Borges, utilizando tecnologias modernas de front-end.

---

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de:

- Criar um site moderno e responsivo
- Aplicar conceitos de UI/UX
- Utilizar animações para melhorar a experiência do usuário
- Praticar arquitetura de front-end com Next.js

O site funciona como uma **landing page**, com navegação por scroll entre seções:
- Home
- Projetos
- Contato

---

## 🧱 Tecnologias utilizadas

- **Next.js** → Estrutura e arquitetura da aplicação
- **React** → Componentização da interface
- **TypeScript** → Tipagem e segurança do código
- **Tailwind CSS** → Estilização e layout
- **Framer Motion** → Animações e interações
- **next/image** → Otimização de imagens
- **next/font** → Otimização de fontes

---

## 🎨 Funcionalidades

- Navegação por scroll suave
- Layout responsivo (mobile e desktop)
- Animações ao entrar na tela
- Seções organizadas por landing page
- Estrutura escalável para integração com CMS futuramente
